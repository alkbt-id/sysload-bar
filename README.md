# SysLoad

Лёгкая утилита для строки меню macOS: коротко показывает загрузку и температуру процессора, а по клику — подробную панель.

<img src="docs/panel-light.png" width="380" alt="panel">

## Что умеет

- **Строка меню**: `CPU 15%` над `TMP 59°` — две мелкие строки, ≈45 pt ширины. Температура — самый горячий датчик кристалла процессора. Цифры обычного цвета, к 80% / 80° желтеют, у 100% / 100° — красные; ширина фиксирована, строка не «прыгает». Пока запущена Ollama, слева от цифр — значок: бледный — ни одна модель не загружена, обычный — модель в памяти, зелёный — модель сейчас отвечает.
- **Панель по клику**:
  - кольца: ЦП, температура, память, GPU, диск;
  - **процессор** — график за 3 минуты (пользователь / система + линия температуры), простой, средняя нагрузка за 1/5/15 минут, температура (макс. и средняя по кристаллу, SSD, батарея), модель чипа и число ядер;
  - **Ollama** — модели в памяти (размер, параметры, квантизация, контекст, GPU или ЦП, через сколько выгрузится), запросы за 5 минут, время ответа, скорость генерации и чтения промпта, сколько моделей скачано;
  - **память** — график, приложения / связанная / сжатая / кэш (как в «Мониторинге системы»), своп, давление памяти;
  - **сеть** — график входящего и исходящего трафика, текущая скорость, объём с момента загрузки, основной интерфейс и IP;
  - **процессы** — топ по ЦП или памяти, вспомогательные процессы сгруппированы по приложению (все `Code Helper` → `Visual Studio Code`).
- **Автозапуск** при входе (LaunchAgent), переключатель в панели.

Опрос — раз в 2 секунды. Список процессов, GPU, диск и статистика Ollama читаются только пока панель открыта, так что в фоне приложение почти ничего не тратит (≈0,5% ЦП). Значок Ollama в фоне следит за её процессами (раз в 6 секунд — какие есть, каждые 2 секунды — их процессорное время); API спрашивается, только когда процессы меняются, и раз в минуту, чтобы не засорять лог Ollama.

## Установка

Нужны macOS 14+ и Swift (Xcode или Command Line Tools).

```bash
./scripts/install.sh     # сборка → ~/Applications/SysLoad.app, автозапуск, старт
./scripts/uninstall.sh   # удалить приложение и автозапуск
```

## Откуда данные

- ЦП — `host_statistics(HOST_CPU_LOAD_INFO)`, разница тиков между замерами.
- Память — `host_statistics64(HOST_VM_INFO64)`, своп — `vm.swapusage`, давление — `kern.memorystatus_vm_pressure_level`.
- Сеть — 64-битные счётчики `NET_RT_IFLIST2` по физическим интерфейсам; туннели VPN (`utun*`), `lo0`, AirDrop не считаются, чтобы трафик не задваивался.
- GPU — `PerformanceStatistics` у `IOAccelerator`.
- Температура — датчики Apple Silicon через `IOHIDEventSystemClient` (`PMU tdie*` — кристалл, `NAND` — SSD, `gas gauge battery`). Это приватный API, он подключается через `dlsym`: если Apple его уберёт, температура просто покажется как «—». На Intel-маках этих датчиков нет.
- Процессы — `ps`.
- Ollama — HTTP API на `127.0.0.1:11434` (`/api/ps`, `/api/tags`, `/api/version`). Запросы и скорость — из лога сервера: `~/.ollama/logs/server.log` у приложения Ollama, `/opt/homebrew/var/log/ollama.log` у `brew services`; читается только дописанное с прошлого раза. Скорость пишет раннер llama.cpp; если её в логе нет — «—». «Отвечает» — когда процессы Ollama (сервер и раннеры моделей, ищутся по пути) тратят больше 0,2 ядра: при генерации это несколько ядер, в простое — ноль, даже если модель работает на GPU. Если Ollama не установлена, раздела нет.

## Разработка

```bash
swift build -c release
.build/release/SysLoad --snapshot docs          # панель и строка меню в PNG на выдуманных данных
.build/release/SysLoad --snapshot /tmp/x --live # то же на реальных данных
```
